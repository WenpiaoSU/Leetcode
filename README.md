# Leetcode解法大全

## 哈希表

|**类型**|**题目**|**核心思想**|
|---|---|---|
|查找型哈希|两数之和|边遍历边查询|
|分类型哈希|字母异位词分组|特征作为key，列表作为value，defaultdict\(list\)|
|存在性哈希|最长连续序列、快乐数|只判断想要的内容是否存在，不关心大小和位置，用set|
|频次比较|赎金信、有效的字母异位词|两个哈希表可以直接比较包含关系，用Counter|
|映射关系|同构字符串、单词规律|双向dict|
|位置记录|存在重复元素 II|元素 → 最近下标|
|原地哈希|缺失的第一个正数|要求空间复杂度为O\(1\)，即不能额外创建哈希表，用原数组作为哈希表|

**判断用dict、set、Counter或defaultdict**：

- 这个东西出现过吗 → set

- 这个东西对应什么 → dict，即\{\}

- 这个东西出现多少次 → Counter or defaultdict\(int\)

- 这一类有哪些东西 → defaultdict\(list\)

**「我要查询什么 → 谁当 Key → 我要保存什么 → 谁当 Value」**
